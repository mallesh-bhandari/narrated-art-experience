# Narrated Art Experience

An AI-powered web application built with Flask, Google Gemini, Pollinations AI, and gTTS, fully containerized using Docker.

## Features
- **AI Narrative Generation:** Uses Google Gemini API to create immersive background descriptions.
- **Dynamic Image Synthesis:** Generates visual artwork based on story context via Pollinations AI.
- **Voice Narration:** Synthesizes audio narration using Google Text-to-Speech (`gTTS`).
- **Containerized:** Dockerized application configured for easy execution and deployment.

---

## Prerequisites
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) installed and running.
- Google Gemini API Key.
